# EZ Across Control 1.1.24

## Windows

- Corrige a atualização com o ADB em uso: o executável e as DLLs do ADB agora
  são instalados juntos numa pasta exclusiva da versão.
- A atualização normal é feita por cima; não é necessário desinstalar. O ADB
  compartilhado não deve ser encerrado para instalar esta versão.
- Se o instalador 1.1.23 estiver aberto mostrando `adb-1.1.22.exe` ou “Acesso
  negado”, cancele-o. Não escolha fechar os aplicativos automaticamente e não
  ignore o erro; use o instalador 1.1.24 quando estiver disponível.

## Android

- Atualização de versão para 1.1.24 (versionCode 22), mantendo a assinatura
  oficial para permitir atualização sobre a instalação existente.
