# Windows 1.1.4

- Only the Windows tray icon changes with the Android connection: the existing icon when connected and the supplied OFF icon when disconnected.
- The logo inside the application and the window/taskbar icon always retain the normal artwork.

The Android production APK remains version 1.1.2. Unchanged native dependencies and corresponding sources remain available in [release v1.1.2](https://github.com/eddesignerez/EzAcrossControl/releases/tag/v1.1.2).
