# Windows 1.1.3

- The Windows header, taskbar window icon and tray icon show the supplied OFF logo while the Android companion is disconnected, including when the server is listening but waiting for a connection.
- A connected Android companion restores the existing logo. Starting the server alone does not count as an Android connection.
- The OFF asset preserves the exact SVG paths and palette provided by the user. The existing connected artwork and layout remain unchanged.

The Android production APK remains version 1.1.2. Unchanged native dependencies and corresponding sources remain available in [release v1.1.2](https://github.com/eddesignerez/EzAcrossControl/releases/tag/v1.1.2).
